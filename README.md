# Kodguider

Steg-för-steg-guider för att lära sig programmera genom att bygga egna spel. Guiderna är skrivna för barn runt tio år som har provat Scratch och vill börja skriva riktig kod.

## Guider

| Guide | Språk | Vad man bygger |
| --- | --- | --- |
| [Rymdskjutaren](rymdskjutaren/) | Python + Pygame Zero | Styr ett rymdskepp och skjut ner fallande rymdblobbar |
| [Ormen](ormen/) | Python + Pygame Zero | Snake: styr en orm som växer när den äter äpplen. Görs efter Rymdskjutaren. |

## Upplägg

Varje guide ligger i en egen mapp:

- `README.md` – själva guiden, steg för steg
- `kod/` – färdig kod för varje steg, att jämföra med om man kör fast
- `bilder/` – bilder som används i guiden
